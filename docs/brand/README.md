# Marca Andoo

- **Nombre**: «Andoo» en el uso diario (barra lateral, ícono, mensajes); «Andoo CreatorStudio» donde hace falta el nombre completo (título de la ventana, instalador, README, bienvenida).
- **Símbolo**: dos círculos (las «o» de Andoo): un objetivo de cámara en contorno blanco y la luz de grabación rellena con el degradado de marca (violeta `#6a4cf5` → magenta `#d44df0` → naranja `#ff7a3d`). En una sola tinta, ambos círculos van en blanco.
- **Tema**: Framer, solo oscuro. Lienzo `#090909`, superficies `#141414` / `#1c1c1c`, tinta `#ffffff` / `#999999`, línea `#262626`, azul `#0099ff` solo para foco, enlaces y selección. Tokens completos en `web/src/theme.css`.
- **Tipografía**: Inter variable (OFL), autoalojada en `web/src/assets/fonts/`.
- **Archivos**: `andoo-mark.svg` (símbolo), `andoo-wordmark.svg` (símbolo + nombre), `andoo-app-icon.svg` (ícono de app, 512 px). Los PNG de `web/public/` se generan desde estos SVG.
