# Avisos de terceros

Andoo CreatorStudio incluye código y recursos de terceros. Sus licencias se respetan tal como se indica aquí.

## Tipografías (SIL Open Font License 1.1)
Inter, Manrope, Poppins, Lato, Montserrat, Reddit Sans y Plus Jakarta Sans se distribuyen bajo la SIL Open Font License 1.1. El texto completo de la licencia, con el aviso de copyright de cada familia, está en el archivo `OFL.txt` de cada carpeta `fonts/`:

- `web/src/assets/fonts/OFL.txt`
- `motion/captions/fonts/OFL.txt`
- `motion/styles/*/fonts/OFL.txt`

## Dependencias de npm
Las bibliotecas que se instalan con `npm ci` (React, Radix UI, cmdk, sonner, lucide, Express, el SDK de Anthropic, Playwright, etc.) traen su propia licencia dentro de `node_modules/` y no se incluyen en este repositorio.
